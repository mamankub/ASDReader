ASDReader portable mode

While this file sits next to ASDReader.exe, ASDReader keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the ASDReaderData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move ASDReader with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\ASDReader and
%LOCALAPPDATA%\ASDReader) instead. If ASDReaderData can't be written (for example on a read-only
drive), ASDReader says so and uses the per-user folders instead.
